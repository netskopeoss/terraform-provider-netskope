# netskope_npa_rules_order (Resource)

Manages the list position of NPA policy rules within a policy group.

Takes a list of rule IDs and reorders them so that the first ID in the list appears first (top), and each subsequent ID appears after the previous one.

**Note:** NPA rules use most-specific-match evaluation. List position does not determine which rule wins — it is for organizational purposes only.

Rules should be created separately with [`netskope_npa_rules`](npa_rules) using `rule_order = { order = "bottom" }` (safe default), then pass their IDs to this resource to set the list position.
