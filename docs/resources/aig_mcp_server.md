# netskope_aig_mcp_server (Resource)

Manages a custom MCP (Model Context Protocol) server in the Netskope AI Gateway. Custom MCP servers allow AIG appliances to proxy MCP traffic to external tool/resource endpoints for AI agent workflows.

Only custom servers (name starts with `mcp-cust-`) can be created, updated, or deleted via Terraform. Predefined Netskope-managed servers are read-only.

## Protocol options

| Value | Description |
|---|---|
| `"http"` | Plain HTTP to the backend |
| `"https-system"` | HTTPS using the system CA bundle |
| `"https-custom"` | HTTPS with a custom CA certificate (supply via `certificate`) |
| `"https-skip"` | HTTPS with TLS verification disabled (not recommended for production) |

## Tool/resource/prompt filtering

The `tools`, `resources`, and `prompts` lists act as allowlists. An **empty list** means no filtering — all items are forwarded. Set explicit values to restrict which MCP capabilities are exposed through this server.

## Example Usage

```terraform
resource "netskope_aig_mcp_server" "my_aigmcpserver" {
  certificate = "-----BEGIN CERTIFICATE-----\nxxxxxxxx\n-----END CERTIFICATE-----"
  host        = "api.githubcopilot.com"
  name        = "mcp-cust-github"
  path        = "/mcp"
  port        = 443
  prompts = [
    "AssignCodingAgent",
    "issue_to_fix_workflow",
  ]
  protocol = "https-system"
  resources = [
    "ui://send-message-input.html",
  ]
  schema = "mcp-http"
  tools = [
    "add_comment_to_pending_review",
    "add_issue_comment",
  ]
}
```

## Schema

### Required

- `host` (String) Hostname or FQDN of the MCP server backend.
- `name` (String) Unique name for the MCP server. Must start with `mcp-cust-` and contain
only lowercase letters, numbers, and dashes (max 19 chars).
- `path` (String) URL path prefix for MCP requests.
- `port` (Number) Port number of the MCP server backend (1–65535).
- `protocol` (String) Connection protocol to the MCP backend:
`http`, `https-system`, `https-custom`, or `https-skip`.
must be one of ["http", "https-system", "https-custom", "https-skip"]

### Optional

- `certificate` (String, Sensitive) PEM-encoded CA certificate. Required when protocol is `https-custom`.
This field is write-only and not returned by the API.
- `prompts` (List of String) List of MCP prompt names to allow through this server (max 100).
Empty array means no filtering — all prompts are allowed.
- `resources` (List of String) List of MCP resource URIs to allow through this server (max 100).
Empty array means no filtering — all resources are allowed.
- `schema` (String) MCP transport schema. Currently only `mcp-http` is supported. Default: "mcp-http"; must be "mcp-http"
- `tools` (List of String) List of MCP tool names to allow through this server (max 100).
Empty array means no filtering — all tools are allowed.

### Read-Only

- `id` (String) Unique identifier for the MCP server.
- `type` (String) Server type. Always "custom" for user-managed servers.
