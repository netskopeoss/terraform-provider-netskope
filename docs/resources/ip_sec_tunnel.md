# netskope_ip_sec_tunnel (Resource)

Manages a Netskope IPSec tunnel. IPSec tunnels connect a network device (firewall, router, or SD-WAN appliance) to a Netskope Point of Presence (POP) for inline traffic inspection.

## Discovering Available POPs

Before creating a tunnel, use the [`netskope_ip_sec_po_ps_list`](../data-sources/ip_sec_po_ps_list) data source to find available Points of Presence for your region. Each POP is identified by a `pop_name` string (e.g. `"US-SJC1"`).

```hcl
data "netskope_ip_sec_po_ps_list" "all" {}

# Inspect output to find POP names near your sites:
output "available_pops" {
  value = data.netskope_ip_sec_po_ps_list.all.pops
}
```

## Primary and Backup Tunnels

For redundancy, create two tunnels pointing to different POPs. Reference both in your network device configuration:

```
Site firewall ──> Primary tunnel (US-SJC1)
             └──> Backup tunnel  (US-LAX1)
```

## Pre-Shared Key

The `psk` field is a sensitive value. Recommendations:

- Store it in a secrets manager (Vault, AWS Secrets Manager) and reference it with `data` sources
- Mark outputs containing the PSK with `sensitive = true`
- The key must match exactly on both the Netskope side and your network device configuration

## X-Forwarded-For IP List

`options.xff.iplist` specifies which source IPs are preserved in the `X-Forwarded-For` header for source identity tracking. Pass an empty list (`[]`) to clear a previously set value.

## Encryption Algorithm

`encryption` must match the cipher configured on your peer device exactly. Mismatched ciphers cause IKE negotiation failures. Use the same value across paired primary/backup tunnels.

## Example Usage

```terraform
resource "netskope_ip_sec_tunnel" "my_ipsectunnel" {
  bandwidth  = 2
  enabled    = true
  encryption = "...my_encryption..."
  notes      = "...my_notes..."
  options = {
    reauth = true
    rekey  = false
    xff = {
      enabled = true
      iplist = [
        "..."
      ]
    }
  }
  pop_names = [
    "..."
  ]
  psk             = "...my_psk..."
  site            = "...my_site..."
  source_identity = "...my_source_identity..."
  source_ip       = "...my_source_ip..."
  source_type     = "...my_source_type..."
  template        = "...my_template..."
  vendor          = "...my_vendor..."
}
```
