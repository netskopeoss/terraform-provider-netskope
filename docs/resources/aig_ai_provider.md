# netskope_aig_ai_provider (Resource)

Manages a custom AI provider in the Netskope AI Gateway (AIG). Custom providers allow AIG appliances to proxy traffic to on-premise, self-hosted, or private AI backends using the OpenAI, Gemini, or Claude API schema.

## Custom Providers Only

Only **custom providers** (names starting with `cust-`) can be created, updated, or deleted via Terraform. Predefined providers (e.g. OpenAI, Anthropic, Google) are read-only in the API and cannot be managed here.

Name constraints: must start with `cust-`, lowercase letters/numbers/dashes only, max 15 characters total.

## Protocol Options

| `protocol` | When to use |
|---|---|
| `"http"` | Plain HTTP to backend (dev/test only) |
| `"https-system"` | HTTPS using the system trust store (public CAs) |
| `"https-custom"` | HTTPS with a custom CA certificate (`certificate` field required) |
| `"https-skip"` | HTTPS without certificate verification (not recommended for production) |

When `protocol = "https-custom"`, provide the PEM-encoded CA certificate in the `certificate` field. This field is write-only — the API does not return it on GET requests. It is not stored in plain text in the provider state.

## API Schema

`schema` controls the API format the provider exposes to clients:

- `"openai"` — OpenAI-compatible REST API (most widely supported)
- `"gemini"` — Google Gemini API format
- `"claude"` — Anthropic Claude API format

The backend must implement the selected schema.

## Example Usage

```terraform
resource "netskope_aig_ai_provider" "my_aigaiprovider" {
  certificate = "-----BEGIN CERTIFICATE-----\nxxxxxxxx\n-----END CERTIFICATE-----"
  host        = "ai.backend.dev.company.com"
  name        = "cust-dev-ollama"
  port        = 443
  protocol    = "https-system"
  schema      = "openai"
}
```

## Schema

### Required

- `host` (String) Hostname or FQDN of the AI backend.
- `name` (String) Unique name for the provider. Must start with `cust-` and contain
only lowercase letters, numbers, and dashes (max 15 chars).
- `port` (Number) Port number of the AI backend (1–65535).
- `protocol` (String) Connection protocol to the AI backend:
`http`, `https-system`, `https-custom`, or `https-skip`.
must be one of ["http", "https-system", "https-custom", "https-skip"]
- `schema` (String) AI API schema the provider exposes. must be one of ["openai", "gemini", "claude"]

### Optional

- `certificate` (String, Sensitive) PEM-encoded CA certificate. Required when protocol is `https-custom`.
This field is write-only and not returned by the API.

### Read-Only

- `id` (String) Unique identifier for the AI provider.
- `type` (String) Provider type. Always "custom" for user-managed providers.
