# netskope_npa_policy_groups (Resource)

Manages an NPA policy group. Policy groups are containers for [`netskope_npa_rules`](npa_rules) and control the order in which groups of rules are evaluated against user connections.

## Why Use a Dedicated Policy Group?

Every Netskope tenant has a built-in **Default** policy group. Rules added to the Default group are evaluated alongside any rules created manually in the UI, making it difficult to isolate Terraform-managed rules from ad-hoc changes.

**Best practice:** create a dedicated policy group for Terraform-managed rules. This:
- Prevents Terraform plan diffs caused by manually-inserted rules in the Default group
- Makes `group_order` predictable — you control where the Terraform group sits relative to others
- Allows rules to be destroyed and recreated without affecting manually-managed policy

## Group Ordering

`group_order` controls the evaluation priority of this group relative to all other groups on the tenant. Lower order values are evaluated first.

| `order` value | Behaviour |
|---|---|
| `"bottom"` | Evaluated after all existing groups |
| `"top"` | Evaluated before all existing groups |
| `"before"` | Inserted before the group identified by `group_id` |
| `"after"` | Inserted after the group identified by `group_id` |

When using `"before"` or `"after"`, supply the `group_id` of an existing group. Use the [`netskope_npa_policy_groups_list`](../data-sources/npa_policy_groups_list) data source to discover group IDs on the tenant:

```hcl
data "netskope_npa_policy_groups_list" "all" {}

locals {
  group_id = {
    for g in data.netskope_npa_policy_groups_list.all.groups : g.group_name => g.id
  }
}

resource "netskope_npa_policy_groups" "terraform" {
  group_name = "terraform-managed"
  group_order = {
    order    = "before"
    group_id = local.group_id["Default"]
  }
}
```

## Example Usage

```terraform
resource "netskope_npa_policy_groups" "my_npapolicygroups" {
  group_name = "...my_group_name..."
  group_order = {
    group_id = "1"
    order    = "after"
  }
  modify_by   = "...my_modify_by..."
  modify_type = "...my_modify_type..."
}
```
