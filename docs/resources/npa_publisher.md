# netskope_npa_publisher (Resource)

Manages an NPA Publisher — the software component installed in your data center that creates an encrypted tunnel to the Netskope cloud and proxies traffic to private applications.

## Publisher lifecycle

Creating this resource registers the publisher object in Netskope but does not install or connect anything. The full workflow is:

1. Create the publisher with this resource — note the `publisher_id` output.
2. Use [`netskope_npa_publisher_token`](npa_publisher_token) to generate a registration token.
3. Install the publisher software on your host and supply the token to register it.
4. Assign the publisher to [`netskope_npa_private_app`](npa_private_app) resources via the `publishers` block.

The `registered` and `status` attributes reflect the connection state after registration.

## Upgrade profiles

By default publishers are assigned to upgrade profile ID 1 (immediate updates). To control when upgrades occur, create a [`netskope_npa_publisher_upgrade_profile`](npa_publisher_upgrade_profile) and set `publisher_upgrade_profiles_id` to its ID.

## Example Usage

```terraform
resource "netskope_npa_publisher" "my_npapublisher" {
  label_ids = [
    "..."
  ]
  lbrokerconnect                = false
  publisher_name                = "npa_publisher_1"
  publisher_upgrade_profiles_id = 1
}
```
