# netskope_urllist (Resource)

Manages a Netskope URL list. A URL list is a named collection of URLs or patterns that can be attached to a [`netskope_custom_category`](custom_category), which is then referenced in a Real-time Protection policy in the Netskope UI.

## URL List Types

The `data.type` field controls how entries are matched:

| Type | Behaviour | Example entry |
|---|---|---|
| `"exact"` | Matches the full domain or URL | `"www.example.com"` |
| `"regex"` | Matches using [RE2](https://github.com/google/re2/wiki/Syntax) regular expressions | `".*\\.example\\.com"` |

## URL Lists Do Not Block Traffic on Their Own

A URL list has no effect until it is attached to a `netskope_custom_category`. The category is then assigned to a Real-time Protection policy in the Netskope UI (or via a policy-as-code tool). The full chain is:

```
URL List  ──>  Custom Category  ──>  Real-time Protection Policy (UI)
```

## Auto-Deploy

The provider automatically deploys the URL list after every create and update — no separate deployment step is needed.

## Example Usage

```terraform
resource "netskope_urllist" "my_urllist" {
  data = {
    type = "exact"
    urls = [
      "www.example.com"
    ]
  }
  name = "...my_name..."
}
```
