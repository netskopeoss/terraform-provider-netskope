# netskope_custom_category (Resource)

Manages a Netskope custom category. A custom category combines URL lists and predefined Netskope categories into a named object that can be referenced in a Real-time Protection policy in the Netskope UI.

## How Custom Categories Fit Into the Policy Chain

Custom categories bridge code-managed URL lists with UI-managed Real-time Protection policies:

```
URL Lists ──>  Custom Category  ──>  Real-time Protection Policy (UI)
```

A custom category by itself does not block or allow traffic — it must be referenced in a Real-time Protection policy in the Netskope UI (Policies → Web → Real-time Protection).

## Included vs. Excluded

| Field | Effect |
|---|---|
| `included_url_lists` | Adds URL list entries to the category scope |
| `excluded_url_lists` | Punches holes in the scope — URLs in these lists are excluded even if matched by included lists |
| `included_predefined_categories` | Adds built-in Netskope category coverage |
| `excluded_destination_profiles` | Excludes by destination profile |

Use `excluded_url_lists` to manage exceptions without creating separate policies.

## ID Types

| Field | ID format |
|---|---|
| `included_url_lists` / `excluded_url_lists` | Numeric string — use `tostring(netskope_urllist.example.id)` for managed lists, or `tostring(data.netskope_urllist.example.id)` for existing lists |
| `included_predefined_categories` | Numeric string — find in UI: Policies → Web → Categories |
| `included_destination_profiles` / `excluded_destination_profiles` | UUID string |

For URL lists not managed in the same Terraform config, use the [`netskope_urllist`](../data-sources/urllist) data source to look up the ID by name:

```hcl
data "netskope_urllist" "existing" {
  id = 42  # numeric ID from Netskope UI
}

resource "netskope_custom_category" "example" {
  name = "my-category"
  included_url_lists = [tostring(data.netskope_urllist.existing.id)]
}
```

## Finding Predefined Category IDs

Predefined Netskope category IDs are tenant-independent integers. Look them up in the Netskope UI under Policies → Web → Categories. Common examples:

- `"107"` — Malware Sites
- `"149"` — Phishing
- `"500"` — Social Networking

## Deletion Constraint

A custom category cannot be deleted while it is referenced in an active Real-time Protection policy. Remove the policy reference in the Netskope UI before running `terraform destroy`.

## Example Usage

```terraform
resource "netskope_custom_category" "my_customcategory" {
  description = "...my_description..."
  excluded_destination_profiles = [
    "..."
  ]
  excluded_url_lists = [
    "..."
  ]
  included_destination_profiles = [
    "..."
  ]
  included_predefined_categories = [
    "..."
  ]
  included_url_lists = [
    "..."
  ]
  name = "...my_name..."
}
```

## Schema

### Required

- `name` (String) Custom category name (unique per tenant, max 100 characters)

### Optional

- `description` (String) Custom category description (max 200 characters)
- `excluded_destination_profiles` (List of String) UUIDs of destination profiles to exclude
- `excluded_url_lists` (List of String) Numeric string IDs of URL lists to exclude (e.g. "19")
- `included_destination_profiles` (List of String) UUIDs of destination profiles to include
- `included_predefined_categories` (List of String) Numeric string IDs of predefined Netskope categories to include (e.g. "500")
- `included_url_lists` (List of String) Numeric string IDs of URL lists to include (e.g. "22")

### Read-Only

- `id` (String) Custom Category UUID
